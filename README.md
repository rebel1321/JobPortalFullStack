🚀 Job Portal Website
After a month of development, the moment every developer eagerly awaits has finally arrived—the project is complete! 🎉

This Job Portal Website is designed to connect job seekers with recruiters, providing a seamless and efficient hiring process.

🛠 Tech Stack
Frontend: React + Tailwind CSS

Backend: Node.js + Express.js

Database: MongoDB

Authentication:

Job Seekers: Managed using Clerk Authentication

Recruiters: Handled through a custom API

🔗 Live Preview
Check out the live demo here: https://jobportalfrontend-ivory.vercel.app/

This project was an incredible learning experience, and I hope it helps both job seekers and recruiters in their journey! 🚀
